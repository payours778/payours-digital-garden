## 需求概述

将本机 `E:\data\jijiandzzd`（Vite + React + Phaser 3 游戏门户 Mini Playbox）中的「保卫阿斗」塔防游戏完整迁移合并到 `E:\data\blog-test`（Next.js）的「灵境」中，在灵境大厅开放与「摸鱼」「农场」并列的「保卫阿斗」入口。合并时完整保留阿斗游戏原有功能与资源，确保不影响现有的摸鱼和农场模块。

## 功能内容

- 在项目文件中单开一个 `game` 目录，下面按单个游戏分子目录存放，如 `game/baoweiadou`。
- 「保卫阿斗」包含：塔防战斗（棋盘布阵、武将合成、资源经营、波次防守、吕布等 BOSS 战）、开始界面（模式/头像/武器/排行榜）、开发者控制台、练兵场（training，9 名武将、台词、菜单、像素小人动画）、独立音效系统、武将/武器/BOSS 单位系统。
- 入口在灵境大厅（tree 页面）的 GAMES 数组中新增「保卫阿斗」卡片，与「灵境农场」「摸鱼房间」并列，点击进入游戏。
- 游戏页面路由为 `/tree/baoweiadou`。

## 边界与约束

- 保留阿斗游戏所有原有功能与静态资源（特效图、音效、练兵场背景/立绘、头像、封面）。
- 不改变现有摸鱼（fish）和农场（farm）的功能、路由与数据。
- 本次暂不加后端持久化（阿斗原为纯本地游戏）；仅加前端页面、代码、资源与入口。
- 需要为前端新增 `phaser`（游戏引擎）与 `zustand`（练兵场 store）依赖。

## 技术栈

- 目标框架：Next.js 16.2.6 App Router（frontend/src/app），React 19.2.4，TypeScript
- 游戏引擎：Phaser 3（新增依赖，需 `dynamic(..., { ssr: false })` 加载避免 SSR 报错）
- 状态管理：zustand（新增，练兵场 store 原样使用）
- 样式：Tailwind v4（globals.css）+ 迁移的阿斗独立样式（作用域隔离）
- 鉴权：复用现有 `@/contexts/AuthContext` 的 `useAuth()`（替换原 `useAppStore` 的用户信息）

## 实现思路

将阿斗游戏从 Vite SPA 迁移到 Next.js App Router，核心是「解耦 + 路径改写 + 资源搬运」：

1. 代码整体复制到 `frontend/src/game/baoweiadou/`，使游戏模块自包含。
2. 解耦外部依赖：用户信息改用 blog-test 的 `useAuth()`；hash 路由/`sessionStorage` 返回逻辑改为 Next.js 路由跳转。
3. 静态资源复制到 `frontend/public/game/baoweiadou/`，并统一改写所有资源引用路径。
4. 阿斗样式从源 `styles.css` 提取迁移，作用域隔离避免与 Tailwind 冲突。
5. 新建 `/tree/baoweiadou` 页面作为游戏挂载点，注册到灵境大厅 GAMES 数组。

## 架构设计

## 实现要点

- **依赖安装**：`cd frontend && npm install phaser zustand`。
- **Phaser SSR**：页面用 `dynamic(() => import('@/game/baoweiadou'), { ssr: false })`；next.config.ts 通常无需额外 webpack 配置（Phaser 客户端渲染），若构建报 canvas/global 错误再补 webpack fallback。
- **资源路径统一改写**：
- `effects/*.png` → `/game/baoweiadou/effects/*.png`（GamePlayScene preload）
- `/assets/audio/sfx/*` → `/game/baoweiadou/audio/sfx/*`（audioConfig）
- `/assets/training-ground/*` → `/game/baoweiadou/training-ground/*`（Stage.tsx）
- `/avatars/*` → `/game/baoweiadou/avatars/*`（GameStartScreen）
- **鉴权解耦**：GameStartScreen 的 `useAppStore(state=>state.user)` 替换为 `useAuth()` 的 `user`，显示 `user.username`。
- **路由解耦**：TowerDefenseGame 的 onBack 改为 `router.back()`（或 `router.push('/tree')`），移除 `window.location.hash` 与 `sessionStorage mini-playbox-return-to` 逻辑；练兵场启动战斗用 `router.push` 代替 hash 跳转。
- **样式隔离**：从源 `styles.css` 提取 tower-defense-*/game-start-*/crt-overlay/weapon-*/avatar-picker-*/tg-* 类，放入 baoweiadou 页面的独立 `<style>` 或 CSS 文件，避免污染全局。
- **兼容性**：阿斗模块与摸鱼/农场完全解耦，不动 fish/ 与 tree/farm/ 现有文件（除 tree/page.tsx 增入口）。
