## 🌱 关于项目

这是一个传统的博客，而是一座**用代码搭建的数字花园**。

在这里，文章是种子，随笔是叶子，音乐是风，照片是阳光——
所有的内容都种在同一个空间里，彼此关联，慢慢生长。

> 💡 **项目哲学**：记录值得留下的东西，让时间成为最好的设计师。

## ✨ 功能一览

| 🌿 模块 | 说明 |
| :---: | :--- |
| 🏠 **首页** | 三栏玻璃拟态布局 · 精选文章轮播 · 随笔推送 · 时间线 · 日历 · 站点统计 · 悬浮音乐球 |

## 🎨 设计亮点

### 👁️ 视觉设计

- 🪟 **玻璃拟态 UI** — 卡片半透明毛玻璃效果，背景图 + 有机形状 blob + SVG 点纹装饰
- 🎨 **双风格配色** — 琥珀暖橙（原型风格）× 紫靛主题色（默认）完美融合
- 📖 **衬线字体** — Noto Serif SC 衬线字体，中文阅读体验拉满
- 🌓 **明/暗双主题** — 亮色 / 暗色 / 跟随系统 三种模式，无白屏闪烁

### 🕹️ 交互体验

- 🎭 **主题切换动画** — 卡片背景、文字颜色、边框颜色全部平滑渐变过渡（0.35s ease）
- 🎶 **悬浮音乐球** — 全局拖拽吸附，点击展开播放器，左右弹出自适应
- 🎠 **精选轮播** — 交叉淡入淡出，封面图 + 文字独立动画
- 🌸 **樱花 / 萤火虫特效** — 随主题切换交叉淡入淡出，跟随系统模式
- 📐 **响应式三栏布局** — 桌面三栏 / 平板两栏 / 手机单栏自动适配

### 🏛️ 架构设计

- 🎨 **自定义主题系统** — 语义化 CSS 变量 + utility class（`surface-card` / `text-primary` / `border-theme`）
- ⚡ **Next.js 16 App Router** — 流式渲染 + 服务端组件
- 💾 **SQLite 文件数据库** — 无需外部数据库，单文件部署，方便备份
- 🛡️ **PM2 进程守护** — 前后端独立进程，开机自启

##  快速开始

### 📦 环境要求

- Node.js **>= 20**
- npm **>= 9**

### 💻 本地开发

```bash
# 1. 克隆仓库
git clone git@github.com:payours778/payours-digital-garden.git
cd payours-digital-garden

# 2. 启动前端
cd frontend
npm install
npm run dev          # ✅ http://localhost:3000

# 3. 启动后端（另开终端）
cd ../backend
npm install
npm run db:init      # 首次运行初始化数据库
npm run dev          # ✅ http://localhost:3001
```

### ⚡ 一键启动

```bash
# 项目根目录
npm run dev:frontend    # 启动前端
npm run dev:backend     # 启动后端
```

## 🛳️ 部署指南

### 🔑 准备工作：配置 SSH 免密（只需一次）

完整图文步骤见 → [SSH密钥配置指南.md](./SSH密钥配置指南.md)

### 🚀 一键部署

> 在本地 PowerShell 中执行一条命令即可。

```powershell
cd e:\data\blog-test
.\deploy.ps1
```

> ✅ **自动化流程**：构建 → 打包 → 上传 → 服务器部署（解压 → 装依赖 → 重启 PM2）
>
> 💾 **数据安全**：数据库文件默认**不打包、不覆盖**，保留服务器真实数据。
